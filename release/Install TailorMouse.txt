INSTALL TAILORMOUSE
macOS 13 or later • Apple Silicon and Intel

1. Drag TailorMouse.app onto the Applications shortcut in this window.
2. Eject the TailorMouse disk image.
3. Open TailorMouse from Applications.
4. Use Permissions… to approve TailorMouse in Accessibility and Input Monitoring.
5. Choose your mappings, then press Start. Stop restores normal mouse handling.

UPDATES
Choose TailorMouse → Check for Updates… in the menu bar, or open Support.
You can opt into automatic checks. Installation still needs your approval.
Updates preserve local profiles and reopen with handling stopped.
If a preview update changes the app's permission identity, remove/re-add only
TailorMouse in Accessibility and Input Monitoring, then reopen it.

FIRST LAUNCH
See Release Info.txt for this download's signing and notarization status.
If it is a preview without Apple notarization, macOS may block the first launch. Apple describes how to review trusted apps under Privacy & Security:
https://support.apple.com/102445
A Developer ID signed, notarized release is needed for a smoother first launch.

MOUSE SUPPORT
Full side-button support currently targets the original Razer Naga Pro across
USB cable, receiver and Bluetooth. Other Naga models are not yet verified.
Avoid running multiple mouse remappers against the same mouse at the same time.

Your settings remain local. This download contains no publisher profiles,
calibrations or account data. No login item is installed.
