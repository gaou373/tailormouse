Add remapping for the original Naga Pro's physical DPI Up and DPI Down buttons over USB cable and receiver. Enable “Remap DPI buttons” in Buttons while stopped, assign actions, then press Start. Stop/Quit restores the original live assignments. Bluetooth DPI-button remapping is not available yet.

- DPI inputs support application profiles, modifier mappings, held shortcuts and chords.
- Live assignments are privately journaled, read back and recovered on failure; stored onboard profiles and hardware DPI values are not changed.
- Buttons → DPI setup… provides restoration after an unplug or crash.
- Existing settings load with DPI-button remapping disabled. Existing Cursor DPI controls remain available.

Preview build: ad hoc signed, not Apple notarized. macOS may require refreshing TailorMouse's existing Accessibility and Input Monitoring entries after installation.
